Sobre o curso

O curso forma profissionais capazes de desenvolver sistemas, manter redes e dar suporte a computadores.

As aulas combinam teoria e prática em laboratório, com projetos reais.

O que você vai aprender

  • Lógica de programação e orientação a objetos
  • Banco de dados relacional e SQL
  • Desenvolvimento web (HTML, CSS e servidor)
